# Plataforma de verificación

Consulta por identificación o código. El resultado aparece en la misma página y el certificado asociado se entrega como archivo PDF previamente cargado por administración.

La interfaz pública reproduce la estructura visual observada en la página de consulta de grados de referencia. El acceso administrativo no aparece en la interfaz pública.

En producción configure `SECRET_KEY`, `ADMIN_USER` y `ADMIN_PASSWORD` en Render.

Los certificados deben ser documentos autorizados; la aplicación no fabrica firmas ni certificaciones institucionales.
